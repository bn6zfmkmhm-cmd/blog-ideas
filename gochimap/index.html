地図に「行った店」を、自分の感想と写真つきで残していけます。まずは Google Maps のAPIキーを入力してください（この端末内に保存され、外部には送信されません）。

APIキーの取り方（無料枠あり・約5分）
  1. Google Cloud Console を開いてログイン
  2. 上部でプロジェクトを新規作成（例: gochi-map）
  3. 「APIとサービス」→「ライブラリ」で次の2つを有効化:
    Maps JavaScript API と Places API (New)
  4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」
  5. 作られたキーをコピーして上の欄に貼り付け
  6. （推奨）そのキーの「アプリケーションの制限」でウェブサイトを選び、このページのURLを許可に追加すると安全です

※ 利用には請求先アカウントの登録が必要ですが、Google Maps には毎月の無料枠があり、個人利用の範囲ならほぼ無料で使えます。
